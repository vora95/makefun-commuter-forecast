A deterministic one-line weather forecast for the fictional city of Wobbleton: sun all morning, rain after six, and a formal apology from the forecast office for last Tuesday's 'light drizzle'. A small Node program writes the same 123 characters to `entry.txt` on every run — no clock, no randomness, no network.

## Run it

```sh
OUTPUT_DIR=./out node main.ts
```
